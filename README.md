# Sistema de Mesa de Partes

Sistema de consola en C# (.NET) para la gestión, registro, consulta y control de expedientes y documentos institucionales.

## Características
- **Registro de Expedientes:** Generación automática de código correlativo (EXP-XXXX).
- **Validación Estricta:** Comprobación de DNI (8 dígitos) y RUC (11 dígitos), tipos de documento autorizados y áreas destino.
- **Detalle de Trámite:** Registro pormenorizado del motivo, compra, servicio o contrato.
- **Búsqueda Dinámica:** Localización instantánea por número de expediente o documento de identidad.
- **Filtrado por Área:** Reporte ordenado cronológicamente por oficina de destino.
